# Anatomie Motion 3D

Kostenlose Web-App zur interaktiven Bewegungsanatomie für Android und Windows (in Entwicklung).

## Ziel
Ein realistischer, frei drehbarer Ganzkörper mit wechselbaren Ebenen für Haut, Muskulatur und Skelett. Übungen wie Liegestütze sollen als steuerbare Animationen mit auswählbaren Muskeln gezeigt werden.

## Status
Der letzte lokal getestete Prototyp ist **v2.7.1**. Die schematische Liegestützbewegung funktioniert; ein echtes 53-Knochen-Ganzkörper-Rig konnte auf Android geladen werden. Die Gelenkachsen sind noch nicht anatomisch kalibriert, und echte Einzelmuskelmeshes sind noch nicht an das Rig gebunden.

**Die eigentlichen HTML-/GLB-Prototyp-Dateien wurden noch nicht in dieses Repository übertragen.** Es ist deshalb noch keine lauffähige Web-App über GitHub Pages verfügbar.
